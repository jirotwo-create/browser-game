# 1.17 — actual world surface UV spirals

The previous release displaced the completed world image. This release removes all intoxication transforms from the presentation shader and instead changes the texture coordinates in the PSX world material fragment shader, before `texture2D(tex, uv)`. Every affected surface samples its own texture; it cannot pull colors from neighboring objects or bend object outlines. The vertex shader and mesh geometry remain unchanged.

After the existing perspective/affine UV blend (including normal close-ground relief), each fragment evaluates a screen-space focus mask. Its texture coordinates then rotate around their own UV center, with radial angular waves, pulsating scale and traveling cross-axis flow. Time advances without camera input. Repeating world maps retain their sampler wrapping, while signs and character materials use their existing sampler settings. Lighting, vertex color, fog, depth and RGB555 quantization follow the new texture sample normally.

Intensity rises smoothly from radius 0.16 to 0.60 in screen-height units from the crosshair, squared to protect the focus area. A tiny 0.0008-weight contribution adds gentle texture movement near the center; the innermost 0.04 radius remains unchanged. Peripheral UV motion can span more than a full texture width. The rotation lever is bounded to one UV unit so highly tiled floors cannot amplify the tiny focus-area effect. UV rotation, not screen position, carries the motion: building edges, occlusion, sky and untextured surfaces remain stable.

Shared strength/time uniforms ensure all world materials, including newly created chapter/signage materials, receive the same state. Native hands/body/gear/smoke use their separate materials/pass. The presentation shader only samples the finished frame at the original coordinates. No intoxication blur, color splitting or screen swirl remains.

The existing ten-second lifecycle is unchanged: 0.35-second onset, sustained peak through 8.5 seconds, final 1.5-second fade. Exhaling heals 25 HP, including a cosmetic effect at full health. Twelve-second cooldown, interrupted-inhale cancellation, holster persistence, pause freeze/hide and chapter/restart reset remain.

The GPU fixture reads the world render target before presentation. It verifies large actual peripheral UV changes, a mostly stable focus region, autonomous texture movement with a fixed camera, zero center/gear changes, and exact restoration at zero strength. Replacing the maps with a solid texture yields byte-identical output during the effect, proving silhouettes and background never move. A material created during intoxication inherits the active shared state. Real-game tests cover healing lifecycle, full-health activation, steady aim, holstering and pause/resume; packaged desktop tests exercise the same effect offline.
